Solara Bay is a 2D top-down open-world crime game that runs in a desktop browser: explore a sun-soaked coastal city on foot and by car, steal vehicles, outrun the police as your wanted level climbs, and run four story jobs for Vic — a taxi delivery, losing the heat, a crew pickup and a bank score. Traffic, pedestrians, combat, a minimap, a day-night clock, procedural sound and localStorage saves included.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step and no network requests: the game is plain static files under `game/`.
